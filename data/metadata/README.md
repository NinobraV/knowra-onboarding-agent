# Metadata

This folder contains metadata and tracking information for document processing.

## Files

### metadata_index.json

Document tracking index that enables intelligent change detection and incremental processing.

**Structure:**

```json
{
  "doc_id_uuid": {
    "doc_id": "doc_id_uuid",
    "source": "path/to/document.md",
    "content_hash": "sha256_hash",
    "page": null,
    "chunk_count": 5,
    "created_at": "2025-10-27T12:00:00",
    "updated_at": "2025-10-27T12:00:00",
    "last_processed": "2025-10-27T12:00:00",
    "title": "Document Title",
    "file_name": "document.md"
  }
}
```

**Purpose:**

- **Change Detection**: Uses SHA-256 content hashing to detect document changes
- **Incremental Processing**: Only re-chunks documents that have been modified
- **Audit Trail**: Tracks creation, update, and processing timestamps
- **Chunk Tracking**: Maintains chunk count for each document

**Generated by**: `pipelines/chunking/document_tracker.py`

## Benefits

The metadata tracking system provides:

1. **Efficiency**: Avoids unnecessary re-processing of unchanged documents
2. **Cost Savings**: Reduces embedding API calls by skipping unchanged content
3. **Consistency**: Maintains stable document IDs across processing runs
4. **Traceability**: Full audit trail of document processing history
