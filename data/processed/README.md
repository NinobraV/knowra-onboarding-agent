# Processed Data

This folder contains chunked and preprocessed documents ready for embedding and indexing.

## Structure

Each processed document is saved as a JSONL (JSON Lines) file with the naming convention:

```text
{doc_id}_chunks.jsonl
```

## Format

Each line in the JSONL file represents a single chunk with the following structure:

```json
{
  "chunk_id": "unique_chunk_identifier",
  "doc_id": "source_document_id",
  "content": "The actual chunk text content...",
  "metadata": {
    "doc_id": "source_document_id",
    "source": "path/to/source/document.md",
    "page": null,
    "timestamp": "2025-10-27T12:00:00.000000",
    "chunk_index": 0,
    "total_chunks": 5,
    "char_count": 1000,
    "word_count": 150,
    "title": "Document Title",
    "file_name": "document.md"
  }
}
```

## Generation

These files are automatically generated by the intelligent chunking pipeline:

- **Pipeline**: `pipelines/chunking/intelligent_chunking_pipeline.py`
- **Chunking Strategy**: Hybrid recursive splitter with sentence window overlap
- **Change Detection**: Only re-processes documents that have changed (via content hashing)

## Usage

The chunked data in this folder can be:

1. **Embedded**: Fed into embedding pipelines (e.g., OpenAI embeddings)
2. **Indexed**: Synchronized with vector databases (e.g., Pinecone)
3. **Retrieved**: Loaded for RAG (Retrieval Augmented Generation) systems

## Metadata Index

Document processing metadata is tracked in `data/metadata/metadata_index.json` to enable efficient incremental updates.
